## Work at Emmanuels Lanka

Production systems I helped design, build and ship.

### [Vantage AI](https://vantageai.eliot.global/)
*Industrial IoT · Real-time solar plant monitoring · Panasian Power PLC*

A real-time data pipeline and centralized SCADA dashboard for solar plants across multiple sites.

- Designed the alerting structure that routes SMS and email notifications to the right people based on plant conditions
- Built and deployed backend API integrations for live data ingestion
- Contributed to the dashboard interface for plant metrics and operational status

`Real-time pipeline` `REST APIs` `SMS & email alerts` `Industrial IoT`

<br />

### [ELIoT SmartFlow](https://smartflow.eliot.global/)
*Garment manufacturing · Production optimization*

Cutting-floor software that connects physical factory operations to digital enterprise management.

- Optimizes fabric layering to cut fabric waste
- Generates QR-coded bundles so cut pieces have a digital footprint
- Improves traceability and visibility across production

`Fabric optimization` `QR bundling` `Traceability` `Manufacturing`

<br />

### ELIoT Handheld RFID
*Enterprise mobile app · Hardware integration · BIT final-year project, University of Moratuwa*

A React Native app paired with N72SH PDA hardware. It tracks garments through bulk UHF RFID scanning and replaces manual counting on the factory floor.

- Built the app in React Native with a Kotlin native module that drives the N72SH scanner
- Implemented bulk tag reading for fast, accurate work-in-progress tracking
- Integrated with the backend and staging APIs of the ELIoT DPM ecosystem

`React Native` `Kotlin` `UHF RFID` `N72SH PDA`
